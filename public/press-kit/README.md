# travi press kit

Open index.html in a browser for the visual guide. All artwork is local and works offline.

- logos/: true SVG outlines and transparent PNGs; color, white, and dark; full logo and symbol.
- icons/: 1024 px app icon, Apple touch icon, Android adaptive layers.
- fonts/: Nunito in five weights with its SIL Open Font License.
- social/: link preview, square post, story, and profile header.
- screenshots/: app screenshots when present.
- press-copy.md: product descriptions and facts.
- brand-guidelines.md: colors, typography, logo use, clear space, and sizes.
- brand-tokens.json: palette for production use.
- asset-manifest.json: dimensions, formats, and transparency for each asset.

SVG files contain real paths, with no linked images or font dependencies. PNG logo backgrounds are transparent. The 1024 px app icon is intentionally opaque for platform compatibility. White logo variants are visible on dark backgrounds.

Brand and artwork belong to the app owner. Use these assets to identify travi; do not imply endorsement. Contact the person who shared this kit for media requests and publishing details.
